# 카마라드 (Carmarade)

**차에 타면 가장 먼저 켜는 앱.** 같은 길을 가는 운전자끼리(아는 사이든 모르는 사이든) 방을 만들어 목적지를 맞추고, 메시지·통화·위치 공유로 함께 이동하는 Pleos Connect용 Android 앱입니다. 현대자동차그룹 차량용 앱 개발 공모전 출품작(팀 Means)입니다.

> 심사하시는 분께: 아래 **1. 5분 안에 확인하기**만 따라 하면 서버 없이 핵심 흐름을 볼 수 있습니다. 온라인 방(두 대 이상의 차량)은 **2번**에 있습니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 앱 이름 | 카마라드 (Carmarade) |
| 대상 기기 | Pleos Connect (Android Automotive, API 28 이상 / 개발·확인은 API 34) |
| 구성 | Android 앱(Kotlin) + 방 서버(Node.js, `server/`) |
| APK | `apk/Means_Carmarade_release.apk` (release 서명) |

## 테스트 환경

- **Pleos Connect 에뮬레이터 v2.1.0** (Android 14 / API 34, Automotive, x86_64), 화면 **2560×1440**, 밀도 160(mdpi), 12.8인치
- 에뮬레이터를 만드는 방법과 화면 크기 설정은 [`docs/sdk-verification.md`](docs/sdk-verification.md)의 "이 PC에서 빌드·실행하는 방법"에 있습니다. 화면 크기를 2560×1440으로 바꾸지 않으면 하단 바가 겹쳐 보입니다.
- 설치한 앱은 에뮬레이터 하단 바 가운데의 **앱 목록(격자 아이콘)** 에서 **카마라드 체험**으로 엽니다. 같은 목록의 "카마라드 SDK 점검"은 개발용 확인 화면입니다.
- 시작 직후에는 Pleos 내비게이션이 먼저 앞에 뜰 수 있습니다. 그러면 카마라드를 한 번 더 열면 됩니다.
- 온라인 방을 시험할 때만 Node.js 22.13 이상이 필요합니다.

## 1. 5분 안에 확인하기 (체험 모드, 서버 불필요)

1. 에뮬레이터를 켜고 APK를 설치합니다. (이전에 debug 빌드를 깔았다면 먼저 `adb uninstall ai.camarade.app.demo`)
   ```sh
   adb install apk/Means_Carmarade_release.apk
   ```
2. 하단 바의 앱 목록에서 **카마라드 체험**을 엽니다(명령으로 열려면 `adb shell am start --user 10 -n ai.camarade.app.demo/ai.camarade.app.MainActivity`). 처음 화면에 "일단 타요. 갈 곳은 그다음에."와 **주말엔, 동해** 동행 카드가 보입니다.
3. 카드의 **준비하기**를 누릅니다. 목적지(강릉 안목해변)와 경유지가 보입니다.
4. 화면을 아래로 내려 **가상 일행의 경로 수락 시뮬레이션** → **이 경로 수락하기** → **동행 주행 체험 시작**을 차례로 누릅니다. 가상 일행 두 명이 함께 있는 주행 화면이 열립니다.
5. 주행 화면에서 왼쪽 아래 프로필 원을 눌러 보세요: 통화·음성 메시지·위치 보기가 뜹니다. 왼쪽 위 버튼은 "쉬어가요"·"잘 따라가고 있어요" 빠른 메시지입니다.

체험 모드는 가상 일행과 가상 위치를 쓰므로 **실제 길 안내가 아닙니다.** 화면 위쪽 상태 표시에 "체험 모드 · 실제 길 안내 아님"이 항상 보입니다.

## 2. 온라인 방 확인하기 (서버 필요)

온라인 방은 서버를 거쳐 서로 다른 차량(에뮬레이터)이 연결됩니다. 서버는 개발 PC에서 켭니다.

1. **서버 켜기** (Node.js 22.13 이상)
   ```sh
   cd server
   npm install
   npm start        # http://127.0.0.1:8787
   ```
2. 앱은 기본으로 에뮬레이터 안에서 `http://10.0.2.2:8787`(= 서버를 켠 PC)에 접속합니다. 따로 설정할 것이 없습니다. (서버 주소를 바꾸는 설정 행은 debug 빌드의 설정 탭에서만 보입니다. 서버 사용법은 [`server/README.md`](server/README.md)를 보세요.)
3. 앱 홈에서 **새 동행 하나 더** → 이름을 쓰고 **온라인 방으로 만들기**가 켜져 있는지 확인한 뒤 **동행 만들기**를 누릅니다. 처음에는 닉네임·차종을 묻습니다. 방이 만들어지면 **6자리 초대 코드**가 크게 나옵니다.
4. **다른 참가자 만들기** (둘 중 하나)
   - 에뮬레이터를 한 대 더 켜서(같은 AVD는 `-read-only`로) **초대 코드로 입장**에 코드를 누릅니다. 입장하면 서로의 멤버 목록이 바로 보입니다.
   - 한 대만 있다면 가상 멤버를 입장시킵니다:
     ```sh
     cd server
     node tools/fake-member.js --code 초대코드 --name 지수 --car "IONIQ 5" --minutes 5
     ```
     입장·경로 수락·출발까지 자동으로 하고 2초마다 위치를 보냅니다.
5. 방 화면에서 **이 경로 수락하기** → **출발하기**를 누릅니다. 위치 공유를 물으면 "정확한 위치"를 고르면 지도에 서로의 위치가 보입니다.
6. 주행 화면에서 상대 프로필 원 → **통화**를 누르면 상대 화면에 받기·거절 버튼이 뜹니다. 에뮬레이터에서 마이크를 쓰려면 PC의 입력 장치와 에뮬레이터 마이크 설정이 맞아야 합니다.

위치는 서버 메모리에만 있고 디스크에 저장하지 않습니다. 통화 음성은 서버가 같은 통화 중인 일행에게 그대로 넘기기만 하고 저장하지 않습니다.

## 구현 범위

**구현됨**
- 방 만들기·입장(6자리 초대 코드, 같은 목적지 공개 방 찾기, 모집 글), 최대 5대
- 목적지·경유지(최대 2개) 개별 수락, 경로가 바뀌면 재수락
- 실시간 위치 공유(정확/대략/숨김, 기본 숨김), 도착 시 자동 종료
- 주행 화면(OpenFreeMap 지도 위 일행 위치, 빠른 메시지, 남은 거리 알림)
- 음성 통화(서버 중계), 받은 메시지·거리 음성 읽어주기(Pleos TTS)
- Pleos 내비 연동(NaviHelper로 목적지·경유지 전달, 경로 보기), 주행 중 화면 제한(CarUxRestrictions)
- 낮·밤 모드, 2칸 분할(절반 폭) 화면

**아직 아닌 것**
- 실제 서버 배포(HTTPS), 계정 복구, 신고·차단
- 실제 차량·이동통신망에서의 시험, 통화 음질·지연 확인, 에코 제거
- 음성 메시지(Pleos STT 연결), 장소 검색(지금은 예시 장소 8곳)
- release APK의 서버 주소는 에뮬레이터용(`10.0.2.2`)입니다. 인터넷 서버로 쓰려면 `-Pcarmarade.serverUrl=https://...`로 다시 빌드해야 합니다.

## 직접 빌드하기

JDK 17, Android SDK 34가 필요합니다(Gradle 8.14, Android Gradle Plugin 8.6.1, Kotlin 2.0.21).

```sh
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

release APK는 서명 키가 필요합니다(키는 저장소에 없습니다). 환경변수 `CARMARADE_KEYSTORE`(경로), `CARMARADE_KS_PASS`를 정하고 `./gradlew assembleRelease`를 실행합니다.

테스트: `cd server && npm test`(서버, Node.js 22.13 이상), `bash scripts/test-core.sh`(앱 핵심 규칙, macOS/Linux 셸 기준이며 `CAMARADE_GRADLE_LIB`에 Gradle의 `lib` 폴더를 지정해야 할 수 있음).

## 폴더 구조

| 위치 | 내용 |
|---|---|
| `app/` | Android 앱. 화면은 `MainActivity.kt`, 주행 화면은 `DriveScreen.kt`, 통화는 `VoiceCall.kt`, 서버 연결은 `net/RoomServer.kt` |
| `core/` | 모임·경로·수락·초대 코드·통화 음성 형식 같은 규칙(앱과 테스트가 함께 씀) |
| `server/` | 방 서버(Node.js). 사용법과 프로토콜은 `server/README.md` |
| `apk/` | release APK |
| `docs/` | 확인 결과와 설계 기록: `sdk-verification.md`(Pleos SDK·에뮬레이터), `voice-call.md`(통화), `native-ui.md`(화면 디자인), `feature-audit.md`(기능 점검) |
| `tests/`, `scripts/` | 핵심 규칙 테스트와 실행 스크립트 |
| `preview/` | 초기에 만든 브라우저 미리보기(현재 앱과 화면이 다름, 참고용) |
