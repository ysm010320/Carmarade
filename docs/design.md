# 카마라드 1차 구현 설계

2026-11-07. 사용자가 Kotlin/Pleos 추천안과 단계별 제작을 선택했다.

## 목적
여러 차량으로 이동하는 크루와 지인들이 모임을 만들고 목적지·경유지를 공유하며 동행 상태를 확인하고 기록을 남기는 차량용 커뮤니티 앱.

## 이번 단계
독립된 Kotlin Android 프로젝트. 가상 멤버를 이용한 오프라인 체험 APK에서 크루/동행 생성, 초대 코드, 장소 선택, 최대 2개 경유지, 경로 버전과 명시적 수락, 일행 현황 지도, 빠른 메시지, 위치공유 켜기/숨기기, 주행 종료와 기록 저장을 구현한다. 실제 위치나 음성이 전송된 것처럼 표시하지 않는다. 실행 중 생성된 모임과 기록은 기기에 저장한다.

제작자 판단: 초기 목표는 2~5대 지인 동행. 공개 번개, 전화, 조명 제어, 사진 업로드, 실사용 서버/로그인은 후속 범위. 화면 편집, 상태 규칙, 차량 연결을 분리한다. 기존 BPT 앱과 독립된 camarade 디렉터리에서 작업한다.

## 접근 방식
1. Kotlin 네이티브 앱 + 교체 가능한 차량 어댑터: 선택한 방식. Pleos에 연결하기 좋고 Android 도구가 필요하다.
2. 브라우저 전용 시연: 화면 검토는 빠르지만 별도의 차량 구현이 필요하다.

## 화면과 상태
- 홈: 내 크루, 예정된 동행, 최근 기록, 생성 버튼.
- 동행: 목적지와 경유지, 경로 수락 상태, 초대 코드, 시작.
- 주행: 간결한 위치 개념도(실제 길 안내 아님), 가상 멤버, 음성/빠른 메시지, 위치공유 상태.
- 기록: 종료 시간·거리·참가 멤버, 후기 저장.
- 모임 종료 시 즉시 공유 해제. 새 모임은 공유 동의를 다시 받는다.
- 주행 상태에서 이름/장소/후기 입력 제한. 차량 상태 불명 시 입력 제한을 기본으로 한다.
- 경로 변경은 새 버전으로 알림. 수락 전에는 해당 멤버의 적용 버전을 바꾸지 않는다.
- 오래된 위치는 오래됨 표시, 숨김 상태에서는 좌표 미표시.

## 구조
`core/` 순수 Kotlin 상태 모델 및 전이, `app/` Android 화면·로컬 저장, `vehicle/` 연결 계약과 시뮬레이터. 실제 SDK 소스는 별도 선택 빌드로 격리한다. 서버 구현 전 멀티 차량 실시간 동기화나 내비 연동 완료를 주장하지 않는다.

## 검증
경로 수락/갱신, 경유지 제한, 권한, 공유 종료, 종료 후 메시지 차단, 입력 검증, 저장 복원 테스트. Android 빌드/정적 검사 실행. 가능하면 에뮬레이터에서 전체 흐름 확인. 실행 환경이 없으면 APK 생성과 구동 검증을 구분해 보고한다.
