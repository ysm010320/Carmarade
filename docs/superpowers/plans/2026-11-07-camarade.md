# Carmarade Implementation Plan

> For agentic workers: execute inline using superpowers:executing-plans.

**Goal:** 실행 가능한 Kotlin 차량용 체험 앱과 재사용할 상태 모델을 만든다.
**Architecture:** Android native views + pure Kotlin domain + vehicle gateway + local persistence.
**Tech Stack:** Kotlin, Android API 28+, Gradle 8+, Java 17.
**Spec:** ../../design.md

## Global Constraints
경유지 최대 2개. 경로 적용은 개별 수락. 공유는 명시적 동의와 종료 시 해제. 가상 일행/개념도임을 표시. 실사용 전송·실제 길 안내를 가장하지 않음.

## Review Focus
1. 경로 변경 후 이전 수락 상태가 남지 않아야 한다.
2. 모임 종료/복원 후 공유가 켜지지 않아야 한다.
3. 비호스트는 확정 경로와 모임 종료를 조작할 수 없어야 한다.
4. 주행 중 입력과 완료 후 메시지를 차단해야 한다.
5. 빈 장소/중복 경유지/저장 실패가 정상 상태로 표시되면 안 된다.
