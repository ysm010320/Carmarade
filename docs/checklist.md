## 네이티브 UI 교체 (브랜치 `feature/ui-redesign`)

`develop`에는 병합했다가 팀원 확정 전이라 되돌렸습니다(PR #6 → PR #9로 revert). 확정되면 revert를 다시 되돌린 뒤 `feature/ui-redesign`을 병합해야 합니다(순서가 바뀌면 변경이 건너뛰어짐). 자세한 내용은 `docs/native-ui.md`.

**목표:** 웹·AI 느낌을 없애고 Pleos 기본 화면과 이어지게. 바탕은 Pleos를 따르고, 포인트는 초록 하나.
